# Source Data Dictionary

- `erp.sales_order`: testata documento; granularità documento.
- `erp.sales_order_line`: riga di vendita/reso; quantità negative per resi.
- `crm.customer`: anagrafica cliente potenzialmente duplicata.
- `erp.inventory_snapshot`: snapshot giornaliero stock.
- `ecommerce.web_order`: pre-fatturazione, utile per controlli ma non source of truth dopo fattura.
